# Data Preprocessing with Python

This repository provides a clean, step-by-step guide to data preprocessing in Python, preparing raw datasets for analysis and machine learning model training. 

The code is designed to be concise, simple, and beginner-friendly.

### Features & Resources
* **Dataset:** Available directly in this repository, or via [Kaggle](https://www.kaggle.com/datasets/yasserh/titanic-dataset).
* **Recommended Environment:** [Google Colab](https://colab.research.google.com/) for quick, zero-setup execution.
